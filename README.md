# HabiTree – Sip ’n Grow

A fun bottle-filling app that helps students build healthy habits while growing trees.

## Project Details
**Theme:** Sustainability @ School  
**App Name:** HabiTree – Sip ’n Grow

HabiTree encourages students to refill their water bottles regularly. Each bottle fill gives the student Growth Points and makes a virtual tree grow. The app helps students build healthy drinking habits while learning about protecting the environment around them

## Unique Selling Point (USP)
- Every refill = virtual tree growth   
- Makes sustainability fun and rewarding for kids  
- Easy and colorful interface for school use  
- Optional classroom leaderboard to reach team goals

## What the Website Does
- Track each time a student fills their bottle.  
- Add Growth Points for every refill.  
- Plants a tree for each refill(could be a herb,shrub,tree). 
- Display daily/weekly progress and fun sustainability tips.
